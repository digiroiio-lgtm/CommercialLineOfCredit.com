# CLOC — CommercialLineOfCredit.com

Phase 1 MVP for CLOC, a U.S. commercial credit information and borrower-acquisition platform.

## Stack
- Next.js
- TypeScript
- Vercel-ready App Router

## Local checks
```bash
npm install
npm run build
npm run lint
npm run typecheck
```

## Lead intake
Set `LEAD_WEBHOOK_URL` in the deployment environment to enable qualification-form delivery.

CLOC / CommercialLineOfCredit.com is not a bank or direct lender.
